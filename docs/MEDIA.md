# Media capture checklist

All media must be captured from the tagged release build on Windows. Do not use mockups, generated artwork, pairing codes that can be mistaken for live sessions, private device data, or misleading connection footage.

1. A full-window screenshot of the idle state.
2. A screenshot with a local pairing code and expiry indicator.
3. A GIF showing view consent and then separate input consent.
4. A short video showing code expiry and local session end.
5. Alt text and a caption that name the release version and explicitly state that no remote connection is made.
